Put a copy of the original ENGLISH game files here (mirroring the game's own folder structure).

HarmonyTools uses this folder (configurable via "SourceEn" in config.json) to:
- look up a dialogue file's WRD companion when it's missing next to the STX file being extracted,
- attach the original English text of each line to the extracted dialogue JSON for comparison.

This folder can be left empty if you don't need either of those features.
